# NeuroLink

NeuroLink es una aplicación de escritorio para el autorregistro de pacientes, el triaje mediante un cuestionario y la gestión de solicitudes de habitación. Se puede manejar con gestos de la mano captados por una cámara, ratón o teclado.

El sistema usa Python, PyQt6, MediaPipe y SQLite. Los registros se guardan localmente. La consulta de DNI con MiAPI Cloud y los resúmenes con OpenRouter requieren internet y se configuran desde **Configuración de integraciones**.
